# カラーコントラスト詳細

## WCAG 2.1 AA コントラスト比要件

- **通常テキスト**: 4.5:1 以上
- **大テキスト**（18px以上、または14px太字以上）: 3:1 以上
- **UIコンポーネント**（ボタン境界線、フォームフィールド境界線等）: 3:1 以上

## ダークモード対応時の注意点

- Tailwind CSS v4 の `dark:` プレフィックスを使用
- ダークモードでもコントラスト比要件は同じ
- 背景色が暗くなるため、テキスト色も適切に調整すること

## 差分ハイライトの配色

| 種別 | 背景色 | テキスト色 | 用途 |
|------|--------|-----------|------|
| 追加 | `#EFF6FF`（blue-50） | `#1E40AF`（blue-800） | 新規追加条文 |
| 削除 | `#FEF2F2`（red-50） | `#991B1B`（red-800） | 削除条文 |
| 修正 | `#FFFBEB`（yellow-50） | `#92400E`（yellow-800） | 変更箇所 |

## 色覚多様性への配慮

- 赤/緑の組み合わせを避ける（赤緑色覚異常に配慮）
- 青/赤/黄を採用（色覚多様性に対応しやすい組み合わせ）
- 色だけでなく、記号（`+`, `-`, `→`）やテキスト装飾（下線、取消線）を併用

## フォーカス表示

- キーボードナビゲーション用: `ring-2 ring-offset-2 ring-blue-500`
- フォーカスリングは常に視認可能にする
- `outline: none` を使う場合は必ず代替のフォーカス表示を提供

## エラー表示

- 赤色 + テキスト「エラー:」+ アイコンの3重表示
- 色だけに頼らない（色覚多様性、モノクロ印刷に対応）
- エラーメッセージはフォームフィールドの直下に表示
