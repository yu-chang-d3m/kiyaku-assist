# 印刷最適化

## 設計原則

- `@media print` で印刷専用スタイルを定義
- A4 縦（210mm x 297mm）レイアウト
- フォントサイズ: **12pt** 以上（高齢者が老眼鏡で読むことを想定）

## 白黒印刷対応

- 色の差分ハイライト → テキスト装飾に変換:
  - **追加**: 左ボーダー（実線）
  - **削除**: 取消線
  - **修正**: 太字
- 背景色は印刷しない（`background: none !important`）
- ボーダーで区別（色に依存しない）

## ページ分割

- 1条文1ページ（`page-break-before: always`）
- 表の途中で改ページしない（`page-break-inside: avoid`）

## ヘッダー・フッター

- ページ番号を表示
- 条文番号を各ページに表示

## チェックボックス欄

- 理事会メンバーが手書きで記入できる空欄を用意
- フォーマット: `□ 採用  □ 修正  □ 保留`
- 条文ごとに判断欄を印刷
