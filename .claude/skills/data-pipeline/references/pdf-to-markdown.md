# PDF → Markdown 変換 詳細手順

## 必要ツール

- `pdftotext` (poppler): `brew install poppler` でインストール済み
  - パス: `/opt/homebrew/bin/pdftotext`
- `pandoc`: インストール済み（docx→md 変換にも使用）

## 変換手順（段階的）

### 1. テキスト抽出

```bash
pdftotext -layout input.pdf output.txt
```

- `-layout` オプションでレイアウト保持（表やインデント）

### 2. 構造認識

- 章（第○章）→ `## 第○章 ○○`
- 条（第○条）→ `### 第○条（○○）`
- 項（1, 2, 3...）→ 番号付きリスト
- 号（一, 二, 三...）→ インデント付き番号リスト

### 3. クリーニング

- ページ番号の除去（`^\s*\d+\s*$`）
- ヘッダー・フッターの除去（繰り返しパターン検出）
- レタースペーシングの除去（`/([ぁ-ん|ァ-ヶ|一-龠]) ([ぁ-ん|ァ-ヶ|一-龠])/g`）
- 連続空行の圧縮（3行以上 → 2行）

### 4. 品質確認

- 条文数のカウント（期待値と一致するか）
- 文字化けチェック
- 表の構造保持確認

## 注意事項

- 国交省 PDF は2段組みの場合がある → `-layout` で大体対応できるが、手動確認必須
- 新旧対照表は左右2列 → Markdown テーブルに変換
- コメント部分（※注釈）は `> ` ブロック引用に変換
