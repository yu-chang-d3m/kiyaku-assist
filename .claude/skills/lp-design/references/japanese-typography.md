# 日本語タイポグラフィ・法的要件

## フォント選定

| フォント | 特徴 | 推奨用途 |
|---------|------|---------|
| Noto Sans JP | Google 製、最も汎用的 | 本文・見出し全般 |
| BIZ UDPGothic | UD（ユニバーサルデザイン）フォント、高齢者に読みやすい | 高齢者ターゲットのサービス |
| LINE Seed JP | モダンで親しみやすい | カジュアルなサービス |

## タイポグラフィ設定

### フォントサイズ（モジュラースケール: Major Third 1.25）

| 要素 | モバイル | デスクトップ |
|------|---------|------------|
| h1 | 28〜32px | 48〜56px |
| h2 | 24〜28px | 36〜42px |
| h3 | 20〜22px | 24〜28px |
| 本文 | 16〜18px | 18〜20px |
| 小テキスト | 14px | 14〜16px |

### 高齢者対応の最低サイズ
- 本文: **18px以上**
- ボタン: **16px以上**
- 注釈: **14px以上**（12px以下は使わない）

### 行間・文字間

```css
/* 日本語本文 */
.body-text {
  font-size: 1.125rem; /* 18px */
  line-height: 1.8;
  letter-spacing: 0.05em;
}

/* 日本語見出し */
.heading {
  font-feature-settings: "palt"; /* プロポーショナル詰め */
  letter-spacing: 0.04em;
  line-height: 1.4;
}
```

### 禁則処理

```css
.jp-text {
  word-break: auto-phrase;   /* Chrome 119+ で自然な折り返し */
  overflow-wrap: anywhere;    /* フォールバック */
  line-break: strict;         /* 厳密な禁則処理 */
}
```

## カラー（マンション管理サービス向け）

### 推奨パレット
- **プライマリ**: ブルー〜ネイビー系（信頼・安定）
- **アクセント**: 1色のみ（CTAボタン等）
- **背景**: 白 + 薄いグレー（#F9FAFB）の交互
- **テキスト**: #111827（ほぼ黒）+ #4B5563（サブ）

### コントラスト比の確認
- 通常テキスト（18px未満）: **4.5:1** 以上
- 大テキスト（18px以上太字、24px以上通常）: **3:1** 以上
- UIコンポーネント: **3:1** 以上

## 日本市場の法的要件

### 必須表示
- **特定商取引法に基づく表記**: フッターにリンク配置
- **プライバシーポリシー**: 個人情報保護法対応
- **総額表示義務**: 価格は必ず税込で表示

### 注意が必要な表現
- 「No.1」: 第三者調査の根拠が必要（景品表示法）
- 「最安」「業界初」: 裏付けなしは優良誤認のおそれ
- 「〇〇円〜」: 最低価格の条件を明示する

### 運営者情報（フッター推奨）
- 運営会社名 / 個人名
- 所在地
- 連絡先（メールまたはフォーム）
- 代表者名（任意だが信頼性向上）

## 日本のBtoC SaaS LP傾向

- 欧米よりも情報量が多いLPが好まれる
- 「安心感」の訴求が特に重要（セキュリティ、サポート体制）
- 無料トライアルは「クレジットカード不要」を明示するとCVR向上
- 「かんたん3ステップ」等の導入障壁を下げる訴求が効果的
