# 非弁行為の境界線詳細（弁護士法72条）

## 弁護士法72条の概要

弁護士法第72条は、弁護士でない者が報酬を得る目的で「法律事件」に関して「法律事務」を取り扱うことを禁止する。

- **条文要旨**: 弁護士又は弁護士法人でない者は、報酬を得る目的で訴訟事件、非訟事件その他一般の法律事件に関して鑑定、代理、仲裁若しくは和解その他の法律事務を取り扱い、又はこれらの周旋をすることを業とすることができない
- **罰則**: 2年以下の懲役又は300万円以下の罰金（弁護士法第77条）
- **趣旨**: 法律生活の公正円滑な営みを妨げ、国民の法律生活上の利益を損なうことの防止

## マンション管理規約改正における位置づけ

### 「法律事件」への該当性

- 管理規約の改正は、区分所有者全員が関与する**自治的規範の定立**行為であり、対立当事者間の「法律事件」には該当しにくい
- 総会決議による規約改正は、団体の意思決定プロセスであり、紛争解決とは性質が異なる
- ただし、以下の場合は「法律事件」に該当するリスクがある:
  - 特定の区分所有者との間で紛争が顕在化している状態での規約改正
  - 滞納管理費の回収を目的とした規約変更
  - 特定の区分所有者を排除する意図での改正

### 「法律事務」への該当性

- 規約案の作成自体は「法律事務」に該当し得るが、標準管理規約をベースとしたテンプレート提供は情報提供に留まる
- 個別マンションの事情に応じた条文のカスタマイズは、程度により「法律事務」に近づく
- AI ツールによる一般的な情報提供・分析は、弁護士の法律事務とは性質が異なる

## AI ツール（キヤクアシスト）として許される範囲

### 許可される行為

| # | 行為内容 | 根拠 |
|---|---------|------|
| 1 | 区分所有法・標準管理規約の条文解説（一般的な法制度の説明） | 法律の一般的解説は誰でも可能 |
| 2 | 改正法のポイント整理・新旧比較表の作成 | 公開情報の整理・比較は情報提供 |
| 3 | 標準管理規約との乖離分析（ギャップ分析） | 客観的な比較分析は法律事務に非該当 |
| 4 | 改正案テンプレートの提示（標準管理規約ベース） | 標準的なテンプレート提供は情報提供 |
| 5 | 総会決議要件の一般的な説明 | 法制度の説明は法律事務に非該当 |
| 6 | 手続きフロー（説明会→理事会→総会）の提案 | 一般的な実務フローの紹介 |
| 7 | 他のマンションの事例紹介（一般化された形で） | 公知の事例情報の提供 |

### 禁止される行為

| # | 行為内容 | 非弁リスクの理由 |
|---|---------|----------------|
| 1 | 特定の区分所有者間の紛争に関する法的判断 | 法律事件に関する法律事務に該当 |
| 2 | 滞納管理費の回収方法に関する具体的助言 | 債権回収は典型的な法律事務 |
| 3 | 損害賠償請求の可否・金額の見積もり | 訴訟事件に関する鑑定に該当 |
| 4 | 訴訟・調停・仲裁の戦略アドバイス | 訴訟事件等の代理・助言に該当 |
| 5 | 特定の管理会社との契約紛争に関する判断 | 法律事件に関する法律事務に該当 |
| 6 | 個別事案への法律の具体的な適用判断 | 個別事案の法的判断は法律事務 |

### グレーゾーン（慎重な対応が必要）

以下の質問に対しては、一般論として情報提供し、具体的事案については弁護士相談を推奨する。

| # | 質問タイプ | 対応方針 |
|---|----------|---------|
| 1 | 特定の規約条文が無効かどうかの判断 | 一般論として強行規定抵触の可能性を指摘し、弁護士相談を推奨。「この条項は区分所有法第○条（強行規定）と矛盾する可能性があります」という形式で回答 |
| 2 | 総会決議の瑕疵に関する質問 | 一般的な瑕疵類型（招集手続の瑕疵、決議要件の不足、特別利害関係人の議決権行使等）を説明し、具体的事案は弁護士相談を推奨 |
| 3 | 管理者の善管注意義務違反 | 一般的な義務内容（善管注意義務の範囲、報告義務、利益相反の禁止等）を説明し、具体的な責任追及は弁護士相談を推奨 |
| 4 | 専有部分の用途変更の可否 | 区分所有法上の原則と標準管理規約の一般的な扱いを説明し、具体的なケースの判断は弁護士相談を推奨 |
| 5 | 共用部分の専用使用権の変更 | 一般的な法的枠組みを説明し、特定の区分所有者に不利益を及ぼす変更は「特別の影響」（第31条第1項後段）の問題として弁護士相談を推奨 |

## ガードレール実装への反映

### 検知パターン（`src/domains/chat/guardrails.ts`）

非弁リスクのある質問を正規表現で検知し、適切なガードレールを適用する。

**検知すべきキーワード・パターン:**

```
高リスク: 訴え(を|の|提起), 損害賠償, 慰謝料, 調停, 仲裁, 弁護士費用,
         判決, 強制執行, 差押え, 仮処分, 仮差押え, 告訴, 告発,
         不法行為, 債務不履行
中リスク: 滞納(.*)(回収|請求|督促), 義務違反(.*)(責任|賠償),
         無効(.*)(訴え|主張|請求), 瑕疵(.*)(取消|無効),
         解任(.*)(請求|訴え)
```

**検知時の応答テンプレート:**

```
[一般的な制度説明を記述]

---
*この点について具体的な事案に基づく判断が必要な場合は、
マンション管理に詳しい弁護士にご相談ください。
お住まいの地域の弁護士会や、日本マンション管理士会連合会を通じて
専門家をご紹介いただくことも可能です。*
```

**false positive への配慮:**

正規表現の設計にあたっては、一般用語と法律用語の区別に注意する:

| 一般用語（検知しない） | 法律用語（検知する） |
|----------------------|-------------------|
| 「住民に訴えかける」 | 「訴えを提起する」 |
| 「損害が大きい」 | 「損害賠償を請求する」 |
| 「調停がとれた雰囲気」 | 「調停を申し立てる」 |
| 「仲裁に入る」（仲介の意味） | 「仲裁手続を開始する」 |

文脈を考慮した検知のために、キーワード単体ではなく周辺の助詞・動詞との組み合わせでパターンを構成する。

## 参考判例・通達

### 判例

- **東京地裁平成29年判決**: マンション管理士による規約改正支援について、標準管理規約に基づくテンプレート提供・一般的な法制度の説明は「法律事件に関する法律事務」に該当しないとした事例。管理士が行ったのは一般的情報提供の範囲であり、個別紛争の解決を目的とした法律事務ではないと判断
- **最高裁平成22年7月20日判決**: 弁護士法72条の「法律事件」は、法律上の権利義務に関して争いや疑義があり、又は新たな権利義務関係の発生する案件を意味するとした

### 通達・ガイドライン

- **日本弁護士連合会ガイドライン**: 隣接法律専門職（マンション管理士、行政書士等）の業務範囲に関する見解。管理規約の一般的な作成支援は許容されるが、紛争性のある案件での法的判断は弁護士の業務範囲とする
- **国土交通省**: マンション管理士は「管理組合の運営その他マンションの管理に関し、管理組合の管理者等又はマンションの区分所有者等の相談に応じ、助言、指導その他の援助を行うことを業務とする」（マンション管理適正化法第2条第5号）

## キヤクアシストでの実装上の注意

1. **免責表示の常時表示**: すべての回答に「本回答は一般的な情報提供であり、個別の法的助言ではありません」を付記する
2. **段階的エスカレーション**: 非弁リスクキーワードを検知した場合、まず一般的な制度説明で対応し、ユーザーが具体的事案の判断を求めた場合は弁護士相談を明確に推奨する
3. **ログ記録**: 非弁リスクパターンが検知された会話ログを保持し、改善に活用する
4. **定期見直し**: 判例・ガイドラインの更新に合わせて、許可/禁止の境界線を定期的に見直す
