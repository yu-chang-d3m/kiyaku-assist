# 規約改正の実務ガイド

## 規約改正の実務フロー

### ステップ1: 現状分析（1〜2か月）
- 現行規約と令和7年版標準管理規約の全文比較
- 改正区分所有法の強行規定に抵触する条文の洗い出し
- 管理会社（日本ハウジング等）の規約案との比較
- 使用細則・各種細則の連動確認

### ステップ2: 専門委員会の設置（理事会1回）
- 理事会決議により規約改正専門委員会を設置
- 委員構成: 理事数名 + 一般組合員 + 外部専門家（マンション管理士等）
- 検討スケジュールの策定（月1回程度の委員会開催が目安）

### ステップ3: 素案作成（2〜3か月）
- 変更条文と変更理由を明確にした改正案（たたき台）
- 新旧対照表の作成（全条文）
- コメント（逐条解説）の整備
- 改正の類型判断: **全面改正**（新旧全文置換） vs **一部改正**（差分のみ変更）
  - 改正点が多い場合は全面改正が望ましい
  - ただし全面改正は理解を得にくい面もあるため、新旧対照表で丁寧に説明

### ステップ4: 管理会社との連携（並行）
- 管理会社の雛形・知見の活用
- 実務運用面の検証（管理費徴収、修繕積立金、保険等）
- 管理委託契約との整合性確認

### ステップ5: 説明会の開催（1〜2回）★最重要ステップ
- 区分所有者への改正案の説明
- 質疑応答の場を確保（十分な時間を取る）
- 書面での質問受付も並行して実施
- **高齢者が多い管理組合では特に丁寧な説明が必要**
- 改正のメリット・必要性を具体的に説明（「法律が変わるから」だけでは不十分）

### ステップ6: 総会招集
- 招集通知に以下を添付:
  - 改正案の全文
  - 新旧対照表
  - 改正理由書
  - 議案説明資料（概要版）
- **招集期間**: 少なくとも総会開催日の2週間前（規約で別段の定めがある場合はそれに従う）
- 改正区分所有法第35条: 会議の目的たる事項を示す必要あり

### ステップ7: 総会決議
- **規約変更 = 特別決議**（区分所有法第31条）
  - 旧法: 区分所有者・議決権の各3/4以上
  - 新法（2026年4月1日以降）: 出席者の3/4以上（定足数: 各過半数）
- 一部区分所有者の権利を特別に害する場合: 当該区分所有者の承諾が必要
- 議事録の作成: 議長・出席理事2名の署名（管理組合法人の場合は理事長）

### ステップ8: 施行・届出
- 施行日の決定（即日 or 特定日）
- 管理会社への改正規約の提供
- 区分所有者全員への改正規約の配布
- 管理組合法人の場合: 必要に応じて登記変更

## よくある問題と対策

### 問題1: 出席者（委任状含む）が定足数に達しない
- **対策**: 事前の委任状・議決権行使書の回収を徹底
- WEB会議での出席も「出席」にカウント（新法）
- 説明会で改正の重要性を訴え、参加を促す

### 問題2: 一部区分所有者の権利を「特別に害する」該当性
- **典型例**: 1階店舗の営業時間制限、ペット飼育の全面禁止（既存飼育者）
- **対策**: 当該区分所有者との事前協議、経過措置の設定
- 判例: 承諾の要否は「受忍限度を超えるか」で判断

### 問題3: 全面改正に対する抵抗感
- **対策**:
  - 新旧対照表で「何が変わるか」を明確に
  - 変更の必要性を3段階で分類: ①法的必須 ②推奨 ③任意
  - ①だけでも先に改正する「段階的改正」も選択肢

### 問題4: 原始規約との整合性
- 公正証書で定められた規約事項（専有部分の範囲等）は特に注意
- 分譲時の原始規約に含まれる特殊条項（デベロッパーの権利留保等）の確認

### 問題5: 使用細則との連動
- 規約改正に伴い使用細則も同時に見直す必要がある場合が多い
- 使用細則の変更は**普通決議**で可能（規約と異なる）
- ただし規約で「使用細則の制定は総会の決議による」と定めている場合はそれに従う

## 改正スケジュールのモデルケース

### パターンA: 2026年4月施行に合わせる場合

| 時期 | アクション |
|------|-----------|
| 2025年10月 | 現行規約の分析開始、専門委員会設置 |
| 2025年11月〜12月 | 素案作成、管理会社と連携 |
| 2026年1月 | 第1回説明会 |
| 2026年2月 | 素案修正、第2回説明会 |
| 2026年3月上旬 | 総会招集通知発送 |
| 2026年3月下旬 | 臨時総会で規約改正決議（施行日を4月1日に設定） |

### パターンB: 2026年度通常総会で改正する場合

| 時期 | アクション |
|------|-----------|
| 2026年1月〜3月 | 現行規約の分析、素案作成 |
| 2026年4月〜5月 | 説明会の開催 |
| 2026年5月〜6月 | 通常総会で規約改正決議 |

※ パターンBの場合、4月1日〜改正日の間は旧規約の一部が法的に無効状態となる点に注意

## 合意形成のコツ

1. **「なぜ変えるのか」を最初に説明** — 法律が変わったから、ではなく、どう管理組合にメリットがあるかを具体的に
2. **変更の影響度を可視化** — 住民の日常生活への影響が大きい項目を先に説明
3. **段階的な情報提供** — いきなり全文を見せず、概要→ポイント→詳細の順で
4. **質問への丁寧な対応** — 「わからない」と言われたら説明不足と受け止める
5. **反対意見の記録と対応** — 議事録に残し、可能な範囲で対案を検討
