# マンション管理規約改定プロジェクト：コンテキストと全体概要

本資料は、直近の法改正や社会情勢の変化に伴う「ご自身のマンション管理規約の改定」に向けたプロジェクトの全体像、これまでの調査結果、および活用できるリソースをまとめた総合的なコンテキスト（背景情報）ドキュメントです。
今後のAI（LLM）との対話や作業において、このファイルを読み込ませることで、これまでの文脈を即座に共有し、スムーズに作業を継続するための土台として機能します。

---

## 1. プロジェクトの目的と背景

*   **目的**：最新の国のガイドラインや法改正に合わせて、居住するマンションの管理規約および使用細則をアップデートし、現代のライフスタイルや将来の建物の老朽化・居住者の高齢化（二つの老い）に対応する。
*   **主な背景（改正のドライバー）**：
    1.  **国土交通省「マンション標準管理規約」の改正（2024年6月）**：名簿の電子化と毎年の更新、修繕積立金の将来に見据えた見える化、「置き配」ルールの整備、EV充電設備や宅配ボックス設置の要件明確化など。
    2.  **法務省「改正区分所有法」（2026年4月施行予定）**：所在等不明な所有者を決議母数から除外する制度の新設、老朽化マンションの再生（建替え・リノベーション等）に向けた決議ハードルの引き下げなど。（※国交省は2025年後半にもこれに合わせた標準規約の再改定を予定しています）

---

## 2. 推奨される今後の対応ステップ

1.  **現行規約のテキストデータ化**：自マンションの現行規約（PDFや紙ベース）をAIが読み込めるテキストデータに変換する。
2.  **差分と課題の抽出（AI活用）**：現行規約と最新の「標準管理規約」をAIで比較し、不足している条文や時代遅れなルールを洗い出す。
3.  **改正原案（ドラフト）の作成（AI活用）**：洗い出した課題に基づき、理事会内で議論するための新しい規約・使用細則のたたき台を作成する。
4.  **住民合意形成**：住民説明会を開催し、総会での特別決議（4分の3以上の賛成）の可決を目指す。

---

## 3. 生成AI（ChatGPT, Claude, NotebookLM等）の活用アプローチ

規約改定やそれに伴う理事会業務のプロセスにおいて、以下のAI活用が既に先行事例として有効性が確認されています。このプロジェクトでも積極的に活用していく方針です。

*   **「標準規約」との差分自動チェック**：手作業で数時間かかる現行規約と標準規約の突き合わせを瞬時に行い、アップデート漏れを特定する。
*   **改正文のドラフト作成とローカライズ**：自マンションの固有の事情（内廊下、スマートロックなど）を指定し、法的整合性のとれた新しい使用細則の条文を作成させる。
*   **ナレッジの一元管理（NotebookLM的活用）**：過去の議事録、現行規約、長期修繕計画などの文書群をAIに一括で読み込ませ、「過去のペットルールの変遷は？」「管理費滞納時の対応は？」といった質問に即座に根拠を示して回答させる理事会内FAQを構築する。
*   **理事会業務の自動化**：録音データからの高精度な議事録作成や、住民向け要約資料の作成により、役員の定常業務負担を軽減する。
