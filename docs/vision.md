# キヤクアシスト — プロジェクトビジョン

**「マンション管理規約の改正を、専門家に頼らずとも、理事会の誰もが自信を持って進められる世界をつくる」**

---

## このプロジェクトが解決する問題

2026年4月、改正区分所有法が施行される。全国約12万の管理組合が管理規約の改正を迫られるが、多くの理事会メンバーにとって規約改正は初めての経験であり、法律の専門知識もない。

現実の選択肢は3つしかない:

| 選択肢 | コスト | 問題 |
|--------|--------|------|
| マンション管理士に委託 | 46〜58万円 | 高額すぎる。多くの管理組合には予算がない |
| 管理会社に依頼 | 約10万円 | 雛形の提供が中心。自分たちのマンション固有の事情に対応しきれない |
| 自力で進める | 0円 | 何から手をつけていいかわからない。間違えるリスクが怖い |

**キヤクアシストは、この3つの選択肢の間にある空白を埋める。**

「専門家ほどの深さはないが、自力よりも遥かに安心して進められる」——AIを活用したセルフサービス型の規約改正支援ツールとして、理事会メンバーの**知識の壁**と**時間の壁**を取り除く。

---

## 上位目的: 高品質な初稿を短時間で作り、理事会レビューの負荷を下げる

キヤクアシストの運用モデルは「AIが最終版を自動確定する」ではない。

```
AIが初稿（たたき台）を生成する
  → 理事会がレビューする（印刷配布 / xlsx で回覧）
    → フィードバック会で議論する
      → プロダクト上で最終版を確定する
```

この運用において、キヤクアシストが最も価値を発揮するのは以下の2点:

1. **レビューに耐える品質の初稿を、短時間で作る** — 専門家が数週間かけて作る新旧対照表の初稿を、AIが数分で生成する。ゼロから書くのではなく、標準管理規約をベースに、マンション固有の事情を差し込む方式で品質を担保する

2. **レビュー台帳として使える資料を出力する** — xlsx に条文番号・重要度・論点グループ・AI案・変更理由・レビュー担当欄・コメント欄・会議結論欄を含む「レビュー台帳」を出力し、理事会メンバーが各自で確認・加筆した結果をフィードバック会に持ち寄れるようにする

---

## 提供する価値

### 1. 「何をすればいいか」がわかる

理事会メンバーにとって最大の不安は「そもそも何から始めればいいのかわからない」こと。キヤクアシストは、規約改正のプロセスを6つのステップに分解し、各ステップで「今やるべきこと」と「次にやること」を明確に提示する。

```
始める → 理解する → 現状を把握する → 差分を分析する → 改正案を作る → 合意を形成する
```

専門家に丸投げするのではなく、**自分たちで理解しながら進める体験**を提供する。

### 2. 「うちのマンションに何が必要か」がわかる

法改正の内容をただ説明するだけでは価値がない。現行規約をアップロードすれば、AIが標準管理規約と比較し、**「あなたのマンションに足りないもの」「変えるべきもの」「そのままでいいもの」**を自動で仕分ける。

60条以上ある規約を1条ずつ読み込む必要はない。**「なぜ変えるのか」という課題を起点**に、優先度（法的必須 / 推奨 / 任意）と課題グループ（電子化対応、管理組合法人化、生活利便性向上...）で整理され、「まず何を見るべきか」がすぐにわかる。

### 3. 「この変更を入れるべきか」を判断できる

各条文について、AIが以下の**判断材料**を必ずセットで提示する:

- **何が変わるのか**（平易な要約）— 画面上・印刷物の両方で常に表示
- **なぜ変えるのか**（法改正の背景、変えなかった場合のリスク）— 画面上・印刷物の両方で表示
- **具体的な条文案**（標準管理規約をベースにしたドラフト）— 新旧対照で表示
- **理事会での説明例**（住民にどう説明すればよいか）— 画面上で折りたたみ表示、印刷物に含む

専門知識がなくても、**「入れるか・入れないか」の判断に必要な情報がすべて揃った状態**で意思決定できる。

### 4. 「理事会に配れる資料」と「レビュー台帳」がすぐにできる

AIが生成した初稿をもとに、**2種類の実務資料**を自動生成する:

**印刷配布用（PDF/Word）**: A4縦・12pt以上の大きめフォント・適切な改ページ・余白・見出し・メモ書き込み欄を備えた新旧対照表。理事会の場で紙を見ながら議論できる品質

**レビュー台帳用（Excel）**: フィルタ・ソート可能な表形式。理事会メンバーに回覧し、各自がコメント・判断を記入して持ち寄る。フィードバック会の結論をプロダクトに戻して最終版を確定するループの土台

### 5. 「オフラインの議論結果」をプロダクトに戻せる

理事会の議論は対面で行われる。印刷物やExcelに書き込まれたフィードバックを、キヤクアシストに戻して反映し、最終確定版を作る経路を提供する。

```
初稿（AI生成）→ レビュー（印刷・Excel回覧）→ フィードバック会 → 反映・最終確定
```

これにより、**AIの出力が一方通行で終わらず、理事会の合意形成プロセス全体を支援**できる。

## 提供しない価値（意図的な制限）

キヤクアシストは万能ツールではない。以下は**意図的に提供しない**:

| 提供しないもの | 理由 |
|--------------|------|
| **法律相談・法律事務** | 弁護士法との抵触を避ける。個別紛争への助言は行わず、必ず専門家への相談を促す |
| **完成品としての規約** | AIが生成するのは「初稿（たたき台）」であり、理事会レビューと専門家確認を経て最終確定する |
| **管理会社の代替** | 管理会社が提供する日常の管理業務や住民対応を代替するものではない |
| **全自動化** | 人間の判断を排除するのではなく、判断に必要な情報を整備する。「AIに任せて終わり」ではなく「AIの助けを借りて自分たちで決める」 |

## 設計の思想

### 課題起点（Issue-first）

条文番号順に改正案を並べるのではなく、**「なぜ変えるのか」という課題を起点**に情報を構造化する。

理事会メンバーが理解するプロセスは以下の順序で進む:

```
① なぜ今、変えなければならないのか？（動機）
② 全部でどのくらいの変更があるのか？（規模感）
③ 何が一番重要なのか？（優先度）
④ 具体的に何がどう変わるのか？（条文の中身）
⑤ うちのマンションに関係あるのか？（文脈化）
⑥ この変更を入れるか入れないか？（判断）
```

画面設計もエクスポートも、この認知プロセスに沿って情報を段階的に提示する。条文の羅列ではなく、「理解→判断」の流れをデザインする。

### 安心の設計

ターゲットユーザーは法律の専門家ではない。高齢の理事会メンバーも多い。**「間違えたらどうしよう」という不安を最小化する**ことが、機能の充実よりも重要。

- 全条文に重要度（法的必須 / 推奨 / 任意）を明示し、「これだけは絶対に対応が必要」がわかる
- 法的必須の条文を保留にした場合は警告を出す
- 「AI が生成した初稿です」の免責を常に表示し、専門家確認を促す
- 保存は自動。「操作を間違えてデータが消えた」を起こさない
- 取り消し・やり直しができる。判断を変えたくなったらいつでも変更可能
- 進捗が常に見える。「あと何件残っているか」「どこまで終わったか」が一目でわかる
- 専門用語には必ず平易な説明を添える。法律用語だけで判断を迫らない

### 段階的な完成と版管理

規約改正は一晩で終わるものではない。理事会で議論し、管理会社と調整し、住民に説明し、総会で決議する。数週間から数ヶ月かかるプロセス。

キヤクアシストは**「途中で止められて、いつでも再開できる」**ことを前提に設計する。セッションが切れてもデータは残り、前回の続きからスタートできる。

さらに、改正案は以下の版で管理される:

| 版 | 意味 | 状態 |
|---|------|------|
| **初稿** | AI が生成した改正案。レビュー前 | 全条文の draft が生成済み |
| **レビュー反映版** | 理事会フィードバックを反映した版 | decision / memo が更新済み |
| **最終確定版** | 理事会で承認された版 | 全条文に最終確定フラグ |

## 成功指標

このプロダクトが価値を出せたかを測る指標:

| 指標 | 目標 | 測定方法 |
|------|------|---------|
| **初稿作成時間** | 規約アップロードから初稿完成まで30分以内 | F2開始〜F4a完了の所要時間 |
| **レビュー準備時間** | 初稿完成からレビュー用資料の出力まで10分以内 | F4a完了〜F6完了の所要時間 |
| **法的必須条文の対応完了率** | 100%（法的必須の保留がゼロ） | importance=mandatory の decision≠pending 率 |
| **最終確定までの往復回数** | 3回以内（初稿→レビュー→反映→確定） | プロジェクトの版更新回数 |
| **ジャーニー完走率** | 70%以上（F0開始→F6完了） | currentStep の遷移データ |

## 事業としての位置付け

### 市場の空白

マンション管理規約の改正を支援するAIツールは、現時点で市場に存在しない。管理士・弁護士は高額、管理会社は雛形提供が中心。**テクノロジーが入り込んでいない領域**にAIで参入する。

### タイミングの優位性

2026年4月の法施行が確定しており、需要のタイミングが明確。施行後は新法の緩和された決議要件（出席者3/4）が使えるため、施行後の2026年4〜6月（通常総会シーズン）がメインの需要期。

### 拡張性

MVP は「単棟型マンションの管理規約」に特化するが、同じアーキテクチャで以下に拡張可能:

- 使用細則（置き配・EV充電・ペット飼育等）のドラフト
- 総会議案書（議案の要領）の自動生成
- 住民説明資料の自動生成
- マルチユーザー（理事会メンバー間の共有・承認ワークフロー）
- 団地型・複合用途型マンションへの対応
